# SUNDIAL — MVP v1 build tasks

**Goal:** from the v1 spec to nine working, logging panels on Bosa's walls for La Meridiana, summer 2027, by way of one artist's proof.

> Status: task list, 25 Nov 2026. The spec is [hardware/MVP.md](hardware/MVP.md) v1, the data plan is [DATA.md](DATA.md), and the wiring is [hardware/mvp-wiring.png](hardware/mvp-wiring.png). Event, print and website tasks stay in the README's *To do*; forking tasks stay in [FORK-TASKS.md](FORK-TASKS.md). This list covers only the panel build, its firmware and its data. Tick items here as they are done.

**The one hard date:** firmware 6.2 is frozen by **May 2027** (SUNDIAL.md 4.1), so the artist's proof must be logging outdoors this winter.

## 1. Parts for the artist's proof (one panel)

- [ ] Buy one of each part in MVP.md 2 (parts 2–17); the panel is already chosen (Trina TSM-185DC01)
- [ ] Check the screw-terminal breakout fits the ELEGOO's row spacing **before** buying nine
- [ ] Industrial microSD: confirm pSLC/SLC and the −25 to 85 °C rating on the datasheet, not the listing
- [ ] Radiation shield: buy one, or print one in ASA and note the file used
- [ ] DS3231: remove the charging diode and resistor if it is a ZS-042
- [ ] Choose R_cell from the reference cell's label I_sc (MVP.md 4.1) and note the value

## 2. Firmware

- [ ] `SUN_CELL` build: GPIO 35 at 2.5 dB, `analogReadMilliVolts` averaged, `R_CELL` constant, no GPIO 25 (MVP.md 6)
- [ ] `LOGGER` build: SHT45 and BME280 on the I2C bus; the columns in DATA.md 3.2 (CF names, kelvin, fractions, empty when missing)
- [ ] Card: one file per day, append and close per line; `station.json` read at start-up
- [ ] Dusk: stop card writes at a set panel voltage, write the day's SHA-256, close, then run the dusk close
- [ ] Admin: download any date range from the card; status shows card, SHT45 and BME280 OK
- [ ] Firmware 6.2 items (README *To do*): admin security, visitors' book, pages built into the firmware, event archive by year
- [ ] First compile and desk test (`BENCH_FAKE 1`), then the MVP build on the bench
- [ ] Update the README's stage table once the flags exist

## 3. Bench build and tests (MVP.md 7)

- [ ] Bench, USB only: every sensor reads; a day of card logging reads back
- [ ] Bench, the cell: reading follows the light; full sun about 1 V
- [ ] **Dusk test:** clean close with hash before brownout, ten times in a row (decides whether the supercaps are needed)
- [ ] Panel day: buck at 5.0 V first; divider checked against a multimeter; wakes at dawn, seals at dusk

## 4. The artist's proof outdoors

- [ ] Mount on a test wall: gnomon and face (GNOMON.md), the cell at the right edge, the shield under the panel, 10 cm clear of the wall
- [ ] Calibrate on a clear noon; run a week; compare the dial with the sky and the SHT45 with a thermometer in shade
- [ ] Through the winter: damp (desiccant, box humidity), terminals, the SHT45 cable, card files intact after every dusk
- [ ] Photograph it for the Photovoltaic Art page
